Run from source

Any platform with Python 3.9 to 3.13 (not 3.14). You get the newest code, ahead of the installers.

git clone --filter=blob:limit=5m https://github.com/ysetbon/OpenStrandStudio
cd OpenStrandStudio
pip install -r requirements.txt
python src/main.py

On Windows, a virtual environment avoids DLL conflicts with other PyQt installs: run python -m venv venv and venv\Scripts\activate before pip install.

What's new

    Updating

    From an installer: run the newer installer. It installs over the old version.

    From source: run git pull in the folder, then start the app again.

    Either way, your saved .oss projects are ordinary files and are left as they are.
